Coding Test Instructions

Rules & Guidelines

1. Code Submission

Write your code in the provided editor. You can run your code to test it before submission.

2. Language Support

You can write code in Python. Select your preferred language from the dropdown menu.

3. Evaluation Process

Your code will be evaluated based on:

  • Correctness of the solution
  • Code efficiency
  • Code readability and structure

Important Warnings

1. Copy-Paste Prevention

Copying and pasting code is strictly prohibited. The system will detect and warn against any copy-paste attempts.

2. Tab Switching

Switching to other tabs or applications is not allowed. The system monitors your activity and will issue warnings for tab switching.

3. Warning System

You will receive warnings for:

  • Copy-paste attempts
  • Tab switching
  • Extended periods of inactivity
After 2 warnings, the test will automatically end.
